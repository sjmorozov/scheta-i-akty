# Счета и акты

Переносимая программа для Windows. Из одной формы она создаёт счёт на оплату и акт выполненных работ в PDF. В обоих документах совпадают номер, заказчик, позиции и суммы. У акта можно указать свою дату.

## Запуск

Открой `Scheta.exe` двойным щелчком. Программа использует .NET Framework, входящий в состав Windows. [Документация Microsoft](https://learn.microsoft.com/ru-ru/dotnet/framework/install/)

1. При первом запуске заполни реквизиты поставщика, если поля ещё пустые.
2. Выбери сохранённого покупателя или введи его реквизиты. Добавь позиции, количество, единицы измерения и цену.
3. Проверь номер, даты и режим НДС. Для режима «Включён в цену» введи ставку в процентах. Сумма НДС выделяется из общей стоимости.
4. Нажми «Создать счёт и акт». Оба PDF появятся в папке счёта. Кнопка «Открыть папку с PDF» покажет их в Проводнике. Во вкладке «История» можно открыть любой из документов.

Программа предлагает номер на единицу больше максимального в истории. Предложенный номер можно изменить вручную. Каждый успешно созданный счёт пополняет выпадающий список покупателей. Для покупателя с тем же ИНН используются последние сохранённые реквизиты.

История и PDF хранятся в папке `%LOCALAPPDATA%\InvoiceAndAct\Счета и акты`. Реквизиты поставщика, сохранённые через окно программы, хранятся в `%LOCALAPPDATA%\InvoiceAndAct\supplier.json`.

## Сборка из исходников

Открой терминал PowerShell в папке проекта. Запусти сценарий сборки.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```

Политика RemoteSigned действует в процессе сборки. Сценарий вызывает встроенный в .NET Framework компилятор `csc.exe` и собирает `dist\Счета.exe`. Параметр `-DefaultsFile` добавляет в локальную сборку стартовые реквизиты поставщика и первый номер счёта. Для локальной сборки используй `-DefaultsFile .\local\defaults.json`.

- `src/Invoice.cs` проверяет введённые данные и рассчитывает суммы.
- `src/Documents.cs` размещает поля, позиции и подписи на страницах.
- `src/PdfFile.cs` записывает PDF с текстом, который можно выделить и скопировать.
- `src/History.cs` сохраняет пару PDF и её запись в истории.
- `src/MainForm.cs` и `src/SupplierForm.cs` отвечают за окна программы.
